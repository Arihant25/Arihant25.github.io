About this project

A Python port of the TerraMetrics Terraform quality metrics tool, originally written in Java. It parses .tf files and computes around 100 structural and quality metrics from their Abstract Syntax Trees. I validated the Python port against 5,594 Terraform blocks to ensure behavioral equivalence with the Java implementation. Read my blog post for a more detailed analysis of the parser and the validation results.
