Looking for You

2021
Single

About this release

This song was created using Vocaloid, a vocal synthesis software. I was experimenting with the software and decided to create a song that captures the feeling of searching for someone special. Ironically, the singer does not exist. The song is in the EDM style and features a catchy melody and upbeat production.
